 Personal Business Card

A simple and responsive personal business card website built using HTML and CSS as part of my frontend development learning journey.



 About the Project

This project is a digital business card designed to present basic personal information in a clean and professional layout.

It was created to practice the fundamentals of HTML structure, CSS styling, layouts, spacing, typography, and responsive design.

 Technologies Used

- HTML5
- CSS3

 Features

- Clean and simple design
- Responsive layout
- Personal profile information
- Contact/social links
- Custom styling with CSS
- Beginner-friendly frontend project

 What I Learned

While building this project, I practiced:

- Creating semantic HTML structures
- Using CSS selectors and properties
- Working with margins, padding, and spacing
- Styling text and images
- Building a structured card layout
- Making a webpage responsive
- Organizing a small frontend project

 Future Improvements

I plan to improve this project by adding:

- JavaScript interactions
- Dark/light mode
- More responsive animations
- Improved accessibility
- Additional social/contact links
